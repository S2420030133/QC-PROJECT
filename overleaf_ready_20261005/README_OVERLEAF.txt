Overleaf upload instructions:
1. Upload qml-vqc-overleaf-project.zip as a new project on Overleaf, or upload its contents into an existing project.
2. The package contains two independent, self-contained LaTeX documents:
   - paper.tex: main manuscript in IEEEtran conference format. Set it as the main document to compile paper.pdf.
   - supplementary_tables.tex: standalone supplementary material with Tables S1-S17 and Figures S1-S3. Set it as the main document to compile the supplementary PDF when the venue accepts a separate supplement.
3. All PNG figures referenced by either source are included beside the sources. Author names, affiliations, and email remain placeholders for the authors to fill in.

The source was regenerated from the saved experiment outputs and the run artifact/metric audit passes. The current manuscript compiled successfully in the built-in editor on 2026-10-16. This interface does not export the compiled PDF, so rendered layout and page count are unverified. Check the target venue template and page limit in Overleaf before submission.
