Overleaf upload instructions:
1. Upload qml-vqc-overleaf-project.zip as a new project, or upload its contents into an existing project.
2. The package contains two self-contained LaTeX documents: paper.tex (main IEEEtran conference manuscript) and supplementary_tables.tex (supplementary material). Select the desired main document in Overleaf.
3. All PNG files referenced by either TeX source are included beside the sources. Author 1/2/3, affiliations, and email remain placeholders for the author to complete.

This environment does not export the compiled PDF, so rendered layout and page count remain to be checked against the target venue's rules.
